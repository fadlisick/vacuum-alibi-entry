A tiny Python program that writes one deadpan robot-vacuum excuse to `entry.txt` for make.fun's The Vacuum's Alibi bounty: the lidar flagged the dust as load-bearing, and this vacuum refuses to be the one that brings the house down.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
